# lp制作-AIの学校演習

LP（ランディングページ）制作の演習用リポジトリです。

**公開URL:** https://m-takuto-shubihiro.github.io/lp-asichool/

## 題材

架空のAIスクール **問学舎（もんがくしゃ）** の受講生募集LP。
非エンジニアの社会人向け・全8回のオンライン講座という設定で、ページの役割は「無料説明会への申込」ひとつに絞っています。

> 主催者の写真は実物です。学校名・受講生の声・料金・日程は架空です。実案件に転用する場合は差し替えてください。

## ファイル構成

```
index.html            1枚もののLP本体（ビルド不要）
css/style.css         スタイル。色・書体・余白は :root のカスタムプロパティに集約
js/main.js            メニュー／絞り込み／View More／気になる回／カウントダウン／スクロール表示
images/organizer.jpg  主催者の顔写真
```

外部依存は Google Fonts（Archivo Black / Zen角ゴシックNew / IBM Plex Mono）だけです。

## プレビュー

`index.html` をブラウザで直接開けば表示されます。ローカルサーバーで確認する場合は次のいずれか。

```powershell
# Node
npx serve .

# Python
python -m http.server 8000
```

## デザインの決めごと

ポップカルチャー系イベント特設サイトのUIパターン（大胆な英日同格の見出し、流れるスローガン帯、
カテゴリ色で色分けしたカードグリッド、お気に入り、カレンダー）を、AI講座の文脈に置き換えて構成しています。

| 項目 | 内容 |
| --- | --- |
| コンセプト | 「答えより先に、問いを」。全8回のタイトルはすべて問い文 |
| ファーストビュー | `WHAT WILL / YOU ASK?` を袋文字＋グラデ塗りで大きく。和文「AIに、何を訊く？」を同格で添える |
| 配色 | 主催者アイコンの紫→桃グラデーションを起点に、`--grad` / `--grad-t` の2系統 |
| カテゴリ色 | 基礎・情報・ことば・データ・資料・しくみ の6色。白文字を載せるため白地に対して4.5:1以上に沈めた値を使う |
| 書体 | 欧文見出し＝Archivo Black、和文＝Zen角ゴシックNew（900/700/500/400）、日付とラベル＝IBM Plex Mono |
| 対応 | スマホ〜デスクトップ、キーボードフォーカス表示、`prefers-reduced-motion`、印刷 |

### インタラクション

| 機能 | 挙動 |
| --- | --- |
| カテゴリ絞り込み | タブで全8回をフィルタ。`aria-pressed` を切り替える |
| View More | 各回の詳細と成果物を開閉（`aria-expanded` + `hidden`） |
| 気になる回 | カードの ✓ で保存。件数をヘッダーと下部バーに表示。`localStorage` に永続化 |
| カウントダウン | 開講日（`js/main.js` の `start`）までの残り日数を表示。過ぎたら日数を出さない |
| 流れるスローガン | CSSのみの無限ループ。ホバーで停止、`prefers-reduced-motion` で停止 |

## 差し替えが必要な箇所

`index.html` 内に `TODO` コメントを置いてあります。

- 主催者の氏名・肩書き・プロフィール本文（`#organizer`）
- 申込フォームのURL（最終CTAの `https://example.com/entry`）
- og:image（1200×630 を `images/` に置いて絶対URLで指定）
- 受講生の声（現状は演習用のダミー・セクション内に注記あり）
- 料金・開講日程（`#schedule` の8行と `js/main.js` の `start` を合わせる）
