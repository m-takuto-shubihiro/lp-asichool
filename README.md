# lp制作-AIの学校演習

LP（ランディングページ）制作の演習用リポジトリです。

**公開URL:** https://m-takuto-shubihiro.github.io/lp-asichool/

## 題材

**AIの学校**（株式会社シュビヒロ主催）の受講者募集LP。
オフラインの実践講義で、AIを実務で使うスキルと考え方を学ぶ2日間の集中講義。
ページの役割は「申し込みフォームへの送客」ひとつに絞っています。

掲載内容は `m-takuto-shubihiro/school-ai-line`（LINE運用リポジトリ）の運営資料から取得しました。

> 本ページは制作演習です。正式な募集ページではありません。申し込みフォームとLINEのリンクはダミーのままです。

## ファイル構成

```
index.html             1枚もののLP本体（ビルド不要）
css/style.css          スタイル。色・書体・余白は :root のカスタムプロパティに集約
js/main.js             メニュー／絞り込み／くわしく見る／気になる章／スクロール表示
images/organizer.jpg   主催者の顔写真（360×360）
images/ogp.jpg         og:image（1200×630／既存ブランドバナーから切り出し）
```

外部依存は Google Fonts（Dela Gothic One / Zen角ゴシックNew）だけです。ピクトグラムは
`index.html` 冒頭にインラインSVGのスプライトとして持たせています（外部SVGへの `<use>` は
ブラウザのセキュリティ制約で読み込めないため）。

## プレビュー

`index.html` をブラウザで直接開けば表示されます。

```powershell
npx serve .            # または
python -m http.server 8000
```

## デザインの決めごと

生成AIが作ったような見た目（紫→桃のグラデーション、ぼかしブロブ、グラデ切り抜き文字、
全部が pill 型）を避け、**印刷物のような作り**に寄せています。

| 項目 | 内容 |
| --- | --- |
| 配色 | 既存ブランドビジュアルに合わせた **紺 `#1e3068` × 山吹 `#f5a623`**。中間色・グラデーションは使わない |
| 面の作り | 単色ベタ塗り＋2pxの黒罫＋**実線のオフセット影**（`5px 5px 0`／ぼかさない）＋網点 |
| 書体 | 見出し・数字＝Dela Gothic One、本文＝Zen角ゴシックNew。欧文の飾りは置かず全文日本語 |
| 見出しの線 | 蛍光ペン風の帯。`box-decoration-break: clone` で行ごとに引く |
| イラスト | ノートパソコンと付箋を手描きのインラインSVGで作成（線幅7の黒罫＋山吹のベタ） |
| カテゴリ色 | 考え方・基礎・ルール・演習・応用 の5色。白文字を載せるので白地に対して4.5:1以上に沈めた値 |
| 対応 | スマホ〜デスクトップ、キーボードフォーカス表示、`prefers-reduced-motion`、印刷 |

CSSに残っているグラデーション指定は、網点（`radial-gradient` ×3）と蛍光ペンの帯
（ハードストップの `linear-gradient` ×1）だけです。`blur()` は使っていません。

### インタラクション

| 機能 | 挙動 |
| --- | --- |
| カテゴリ絞り込み | タブで全11章をフィルタ。`aria-pressed` を切り替える |
| くわしく見る | 各章の説明を開閉（`aria-expanded` + `hidden`）。ボタン文言も切り替わる |
| 気になる章 | カードの ✓ で保存。件数をヘッダーと下部バーに表示。`localStorage` に永続化 |
| 流れる帯 | CSSのみの無限ループ。ホバーで停止、`prefers-reduced-motion` で停止 |
