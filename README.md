# lp制作-AIの学校演習

LP（ランディングページ）制作の演習用リポジトリです。

**公開URL:** https://m-takuto-shubihiro.github.io/lp-asichool/

## 題材

架空のAIスクール **問学舎（もんがくしゃ）** の受講生募集LP。
非エンジニアの社会人向け・全8回のオンライン講座という設定で、ページの役割は「無料説明会への申込」ひとつに絞っています。

> 学校名・講師・受講生の声・料金・日程はすべて架空です。実案件に転用する場合は差し替えてください。

## ファイル構成

```
index.html      1枚もののLP本体（ビルド不要）
css/style.css   スタイル。色・書体・余白は :root のカスタムプロパティに集約
js/main.js      スマホメニューの開閉 と スクロール表示のみ
images/         og:image や講師写真の置き場（現状は空）
```

外部依存は Google Fonts（しっぽり明朝B1 / Zen角ゴシックNew / IBM Plex Mono）だけです。

## プレビュー

`index.html` をブラウザで直接開けば表示されます。ローカルサーバーで確認する場合は次のいずれか。

```powershell
# Node
npx serve .

# Python
python -m http.server 8000
```

## デザインの決めごと

| 項目 | 内容 |
| --- | --- |
| コンセプト | 「答えより先に、問いを」。カリキュラム各回のタイトルもすべて問い文にしている |
| ファーストビュー | 縦組みの明朝で「AIに、何を訊くか。」。`text-combine-upright` で AI だけ正立させ、背景に原稿用紙の罫を敷く |
| 配色 | 藍 `#1b2a4a` / 深藍 `#101a30` / 白藍 `#eef1f6` / 青磁 `#7fbfa8` / 山吹 `#e0a32e`（CTA） |
| 書体 | 見出し・縦組み＝しっぽり明朝B1、本文＝Zen角ゴシックNew、ラベルと数字＝IBM Plex Mono |
| 対応 | スマホ〜デスクトップ、キーボードフォーカス表示、`prefers-reduced-motion`、印刷 |

## 差し替えが必要な箇所

`index.html` 内に `TODO` コメントを置いてあります。

- 申込フォームのURL（最終CTAの `https://example.com/entry`）
- og:image（1200×630 を `images/` に置いて絶対URLで指定）
- 講師の写真（`.face` を `<img>` に置き換える）
- 講師プロフィール・受講生の声・料金・開講日
